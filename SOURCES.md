# Data sources and citations

Every covariate `sigmutselcovs` builds comes from an external
public resource. This file documents each one: what it is, exactly
which dataset/version/accession this package uses, how the source
asks to be cited, and any acknowledgment text its data-use policy
requires.

When adding a new cancer type (see `DEVELOPMENT.md` and, while it
still exists, the `add-tissue` skill), record any new
dataset/accession here in the same format.

## GTEx (gene expression)

**What**: median gene-level TPM per tissue from the Genotype-Tissue
Expression project, used as the baseline (non-tumor) expression
covariate — one representative GTEx tissue per cancer type (e.g.
`Breast_Mammary_Tissue` for BRCA), mapped via
`data/gene_expression/gtex_tcga_mapping.json`.

**Dataset used**: GTEx Analysis **v10**
(`GTEx_Analysis_v10_RNASeQCv2.4.2_gene_median_tpm.gct`), fetched by
`sigmutselcovs download-gtex` from
`storage.googleapis.com/adult-gtex/bulk-gex/v10/`.

**Cite**:
> The GTEx Consortium (2020). The GTEx Consortium atlas of genetic
> regulatory effects across human tissues. *Science* 369(6509),
> 1318–1330. https://doi.org/10.1126/science.aaz1776

**License / use**: GTEx open-access data is available without
restriction for research use; see the
[GTEx data use policy](https://gtexportal.org/home/documentationPage)
for the (minimal) terms.

**URL**: https://gtexportal.org/

## GDC / TCGA (gene expression, per-sample)

**What**: per-sample RNA-seq gene expression (STAR — Counts
workflow: `unstranded`, `stranded_first`, `stranded_second`,
`tpm_unstranded`, `fpkm_unstranded`, `fpkm_uq_unstranded`) for both
tumor and matched-normal samples of a TCGA project, queried live
from the GDC files API (`gdc.py`) — no checked-in manifest.

**Dataset used**: TCGA-COAD (524 files) and TCGA-BRCA (1,231
files) as of 2026-08; any project's current inventory is whatever
`sigmutselcovs download <PROJECT> --which gexp` returns at run
time (`check_updates()` tracks the file count for drift).

**Cite the GDC infrastructure**:
> Grossman, R. L., Heath, A. P., Ferretti, V., Varmus, H. E., Lowy,
> D. R., Kibbe, W. A. & Staudt, L. M. (2016). Toward a Shared
> Vision for Cancer Genomic Data. *New England Journal of
> Medicine* 375(12), 1109–1112.
> https://doi.org/10.1056/NEJMp1607591

**Acknowledge TCGA** (per NCI guidance, required for any TCGA-
derived result): include a statement such as *"The results shown
here are in whole or part based upon data generated by the TCGA
Research Network: https://www.cancer.gov/tcga."* When citing a
specific cancer type's molecular characterization, prefer that
project's original TCGA marker paper if the analysis leans on
tumor biology beyond raw expression counts (find via
https://gdc.cancer.gov/about-data/publications/).

**License / use**: TCGA/GDC open-access data (no dbGaP
authorization needed) is unrestricted for research use, per the
[GDC data use policy](https://gdc.cancer.gov/access-data/data-access-processes-and-tools).

**URL**: https://portal.gdc.cancer.gov/

## TCGA ATAC-seq (chromatin accessibility)

**What**: open-chromatin (ATAC-seq) signal, gene body and promoter
window summaries, per tumor sample.

**Dataset used**: the Corces et al. pan-cancer TCGA ATAC-seq
normalized bigWig release, one tarball per cancer type
(`gdc_uuid` in the registry — e.g. COAD:
`26b96cd9-dce0-4340-b15f-9e0afbb6312c`, BRCA:
`f1c06cd3-cf35-41cc-bc75-6db273c94273`); 23 of the 33 TCGA cancer
types are covered (see `tissues_TODO.md`).

**Cite**:
> Corces, M. R., Granja, J. M., Shams, S., Louie, B. H., Seoane,
> J. A., Zhou, W., Silva, T. C., … Chang, H. Y. (2018). The
> chromatin accessibility landscape of primary human cancers.
> *Science* 362(6413), eaav1898.
> https://doi.org/10.1126/science.aav1898

**License / use**: distributed through GDC as open-access data;
same terms as other GDC open data.

**URL**: https://gdc.cancer.gov/about-data/publications/ATACseq-AWG

## Roadmap Epigenomics (histone marks)

**What**: ChIP-seq fold-change-over-input signal for seven histone
marks (H3K4me1/3, H3K9ac/me3, H3K27ac/me3, H3K36me3), gene body and
promoter window summaries, per reference epigenome.

**Dataset used**: consolidated epigenomes selected per cancer type
by primary-site match — e.g. COAD uses E075 (Colonic Mucosa), E106
(Sigmoid Colon), E101/E102 (Rectal Mucosa); BRCA uses E027 (Breast
Myoepithelial), E028 (Breast vHMEC), E119 (HMEC). Not every
`(epigenome, mark)` pair has a track (see `SKILL.md`'s "404s are
normal" note) — the registry's `roadmap.eids` records which
epigenomes were used per project; missing marks are silently
skipped at download time.

**Cite**:
> Roadmap Epigenomics Consortium, Kundaje, A., Meuleman, W., Ernst,
> J., Bilenky, M., Yen, A., Heravi-Moussavi, A., … Kellis, M.
> (2015). Integrative analysis of 111 reference human epigenomes.
> *Nature* 518(7539), 317–330.
> https://doi.org/10.1038/nature14248

**License / use**: Roadmap Epigenomics data are public domain /
unrestricted for research use (NIH Common Fund program); the
project has not accepted new data since ~2015 (the release is
"frozen").

**URL**: https://egg2.wustl.edu/roadmap/web_portal/

## ENCODE Repli-seq (replication timing)

**What**: per-gene replication timing, either as multiple S-phase
fractions (`fraction_bigwigs` source type) or a single smoothed
early/late signal (`wavelet` source type) — see
`DEVELOPMENT.md` and the `add-tissue` skill's
`references/lessons.md` for the two-cohort catalog (UW 6-fraction
vs. Gilbert-lab wavelet) and which cell lines belong to each.

**Dataset used**: BRCA uses the UW/Stamatoyannopoulos 6-fraction
Repli-seq for MCF-7 (accessions `ENCFF001GSV`, `ENCFF001GTD`,
`ENCFF001GTF`, `ENCFF001GTH`, `ENCFF001GTK`, `ENCFF001GSX`,
G1b→G2 in order). The per-gene mean replication time (MRT) is
computed as the length-weighted average over S-phase midpoints —
mathematically the same weighted average defined for this assay by
Hansen et al. (2010).

**Cite the ENCODE resource**:
> The ENCODE Project Consortium (2012). An integrated encyclopedia
> of DNA elements in the human genome. *Nature* 489(7414), 57–74.
> https://doi.org/10.1038/nature11247
>
> Davis, C. A., Hitz, B. C., Sloan, C. A., Chan, E. T., Davidson,
> J. M., Gabdank, I., Hilton, J. A., … Cherry, J. M. (2018). The
> Encyclopedia of DNA elements (ENCODE): data portal update.
> *Nucleic Acids Research* 46(D1), D794–D801.
> https://doi.org/10.1093/nar/gkx1081

**Cite the Repli-seq assay/method**:
> Hansen, R. S., Thomas, S., Sandstrom, R., Canfield, T. K.,
> Thurman, R. E., Weaver, M., Dorschner, M. O., Gartler, S. M. &
> Stamatoyannopoulos, J. A. (2010). Sequencing newly replicated DNA
> reveals widespread plasticity in human replication timing.
> *Proceedings of the National Academy of Sciences* 107(1),
> 139–144. https://doi.org/10.1073/pnas.0912402107

**ENCODE's citation policy is stricter than most sources** — when
publishing, ENCODE requires *all three* of: (1) citing the two
consortium papers above (plus the current portal paper if newer),
(2) an acknowledgment crediting "the ENCODE Consortium and the
ENCODE production laboratory(s)" that generated the specific
dataset(s) used, and (3) listing the specific accession numbers
used (`ENCSR…` experiment / `ENCFF…` file, as recorded per-project
in `data/projects.json`). See
https://www.encodeproject.org/help/citing-encode/ for the current
wording.

**License / use**: unrestricted for research use, no embargo.

**URL**: https://www.encodeproject.org/

## GEO GSE137764 (16-fraction Repli-seq)

**What**: 16-fraction Gaussian-smoothed, scale-normalized Repli-seq
heatmaps — the richest replication-timing format this package
supports (`mat` source type).

**Dataset used**: COAD uses the HCT116 file from this series
(`GSE137764_HCT_GaussiansGSE137764_mooth_scaled_autosome.mat`); the
series also has H1 and H9 (plus mouse) but no other cancer-relevant
cell lines as of 2026-08.

**Cite** (same paper as the GEO series, already in
`article/references.bib` as `Zhao2020`):
> Zhao, P. A., Sasaki, T. & Gilbert, D. M. (2020). High-resolution
> Repli-seq defines the temporal choreography of initiation,
> elongation and termination of replication in mammalian cells.
> *Genome Biology* 21, 76. https://doi.org/10.1186/s13059-020-01983-8

**License / use**: GEO-deposited data, unrestricted for research
use per NCBI/GEO policy.

**URL**: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE137764

## GENCODE (gene annotation)

**What**: not a covariate itself, but the gene-body and
promoter-window coordinates every other source is summarized
over. Assembly/version is picked per covariate block by the
registry's `assembly` field: `hg19` blocks (Roadmap, ENCODE-sourced
replication timing) use GENCODE v19; `hg38` blocks (TCGA ATAC-seq,
GDC gene expression, the COAD HCT116 MAT) use GENCODE v38. This is
the source of the "extra NaN in hg19 blocks" pattern documented in
`DEVELOPMENT.md`.

**Cite**:
> Frankish, A., Diekhans, M., Ferreira, A.-M., Johnson, R.,
> Jungreis, I., Loveland, J., Mudge, J. M., … Flicek, P. (2019).
> GENCODE reference annotation for the human and mouse genomes.
> *Nucleic Acids Research* 47(D1), D766–D773.
> https://doi.org/10.1093/nar/gky955

**License / use**: freely available for research and commercial
use.

**URL**: https://www.gencodegenes.org/
